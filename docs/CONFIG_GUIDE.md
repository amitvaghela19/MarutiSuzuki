# Config guide (non-developers)

1. **suppliers.yaml** — who supplies what, lead times, capabilities
2. **parts.yaml** — which suppliers can serve each part
3. **mcdm.yaml** — ranking criteria and weights
4. **thresholds.yaml** — when to dual-source or emergency split
5. **scenarios.yaml** — disruption shocks for simulation
6. **data_sources.yaml** — countries and API series IDs

After edits, click **Run analysis** in the UI.
